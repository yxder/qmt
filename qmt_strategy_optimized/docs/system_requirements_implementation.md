### 1.2 详细数据流程说明

1. **数据采集阶段**
   - 时间：每个交易日9:15-9:25集合竞价期间
   - 数据源：全市场A股股票
   - 采集内容：
     - 竞价成交量、涨跌幅、资金流入流出情况
     - 委托单数据、封单量、封单比例
     - 板块信息、流通市值等基本面数据
   - 采集方式：多线程并行采集，确保数据完整性和实时性
   - 数据存储：内存临时存储，用于后续模块处理

2. **板块识别阶段**
   - 输入：数据采集模块提供的竞价数据
   - 处理流程：
     - 为每个股票添加板块信息
     - 计算各板块的多维度指标（成交量增长率、涨跌幅偏离度、资金流入强度等）
     - 综合评分并排序
     - 筛选TOP热门板块
   - 输出：热门板块列表及相关指标

3. **个股筛选阶段**
   - 输入：
     - 数据采集模块提供的竞价数据
     - 板块识别模块提供的热门板块列表
     - 历史数据（可选）
   - 处理流程：
     - 在热门板块内筛选股票
     - 应用筛选条件（近3日成交量持续放大、早盘价格异动等）
     - 计算个股综合评分
     - 排序并形成个股候选池
   - 输出：个股候选池，带有综合评分

4. **模型预测阶段**
   - 输入：
     - 个股筛选模块提供的候选个股数据
     - 特征数据（可选）
   - 处理流程：
     - 提取或生成特征数据
     - 应用预训练的机器学习模型进行预测
     - 预测未来30分钟内上涨概率、当日封板成功率、次日溢价空间
     - 计算预测置信度
   - 输出：带有预测结果的候选个股数据

5. **风险评估阶段**
   - 输入：
     - 模型预测模块提供的带有预测结果的候选个股数据
     - 市场数据（可选）
   - 处理流程：
     - 评估市场整体情绪风险
     - 评估个股风险指标（波动率风险、流动性风险、政策风险等）
     - 计算综合风险评分
     - 生成风险评级和风险预警
   - 输出：带有风险评级的候选个股数据

6. **决策建议生成阶段**
   - 输入：风险评估模块提供的带有风险评级的候选个股数据
   - 处理流程：
     - 计算综合决策得分
     - 生成买入优先级
     - 计算建议买入价格区间
     - 计算仓位配置比例
     - 计算止盈止损点位
     - 生成完整的决策建议
   - 输出：完整的投资决策建议

7. **回测验证阶段**
   - 输入：
     - 历史数据
     - 策略决策建议
   - 处理流程：
     - 模拟历史交易
     - 计算回测指标（年化收益率、夏普比率、最大回撤等）
     - 生成回测报告
   - 输出：回测结果和分析报告

### 1.3 数据质量保证机制

1. **数据完整性检查**
   - 检查每个股票的数据字段是否完整
   - 检查数据记录数量是否符合预期
   - 对缺失数据进行填充或标记

2. **数据准确性验证**
   - 检查数据值是否在合理范围内
   - 验证数据的逻辑一致性（如最高价≥收盘价≥最低价）
   - 与历史数据进行对比验证

3. **数据实时性保证**
   - 使用多线程并行采集，降低采集延迟
   - 设置采集超时机制，确保在9:25前完成数据采集
   - 对采集过程进行监控，及时处理异常情况

## 2. 指标定义量化

### 2.1 数据采集模块指标

| 指标名称 | 指标定义 | 计算公式 | 取值范围 | 数据类型 |
|---------|---------|---------|---------|---------|
| 竞价涨跌幅 | 集合竞价期间的价格涨跌幅 | (竞价价格 - 前收盘价) / 前收盘价 | [-10%, 10%] | 连续型 |
| 竞价成交量 | 集合竞价期间的成交量 | - | [0, +∞) | 连续型 |
| 竞价成交量比 | 竞价成交量与昨日成交量的比值 | 竞价成交量 / 昨日成交量 | [0, +∞) | 连续型 |
| 竞价换手率 | 竞价成交量与流通股本的比值 | 竞价成交量 / 流通股本 | [0, 100%] | 连续型 |
| 竞价封单金额 | 集合竞价期间的封单总金额 | 封单数量 × 封单价格 | [0, +∞) | 连续型 |
| 竞价封单比例 | 封单数量与流通股本的比值 | 封单数量 / 流通股本 | [0, 100%] | 连续型 |
| 资金净流入 | 集合竞价期间的资金净流入金额 | 买入资金 - 卖出资金 | (-∞, +∞) | 连续型 |
| 大单资金流入 | 集合竞价期间的大单资金流入金额 | 大单买入金额 - 大单卖出金额 | (-∞, +∞) | 连续型 |

### 2.2 板块识别模块指标

| 指标名称 | 指标定义 | 计算公式 | 取值范围 | 权重 |
|---------|---------|---------|---------|------|
| 成交量增长率 | 板块内股票的平均成交量增长率 | (当日竞价成交量 - 昨日平均成交量) / 昨日平均成交量 | (-∞, +∞) | 20% |
| 涨跌幅偏离度 | 板块平均涨跌幅与大盘涨跌幅的差值 | 板块平均涨跌幅 - 大盘涨跌幅 | (-∞, +∞) | 25% |
| 资金流入强度 | 板块资金流入金额与板块总市值的比值 | 板块资金净流入 / 板块总市值 | (-∞, +∞) | 25% |
| 板块联动性 | 板块内股票涨跌幅的相关性 | 板块内股票涨跌幅的平均相关系数 | [-1, 1] | 15% |
| 涨停密度 | 板块内接近涨停股票的比例 | 接近涨停股票数量 / 板块内股票总数 | [0, 1] | 15% |
| 综合评分 | 板块的综合评分 | 各项指标 × 权重之和 | (-∞, +∞) | 100% |

## 3. 模型可解释性实现

### 3.1 特征重要性分析

#### 3.1.1 SHAP值分析

使用SHAP（SHapley Additive exPlanations）值进行特征重要性分析，解释模型预测结果。

**实现方法：**
```python
# 使用SHAP解释预测结果
def explain_predictions(self, features: pd.DataFrame) -> pd.DataFrame:
    # 初始化SHAP解释器
    if self.shap_explainer is None:
        self.shap_explainer = shap.TreeExplainer(main_model)
    
    # 计算SHAP值
    shap_values = self.shap_explainer.shap_values(features)
    
    # 转换为DataFrame
    shap_df = pd.DataFrame(shap_values[1], columns=features.columns, index=features.index)
    
    # 添加SHAP值之和作为综合影响
    shap_df['shap_sum'] = shap_df.sum(axis=1)
    
    return shap_df
```

**输出结果：**
- 每个特征对模型预测结果的贡献值（SHAP值）
- 特征重要性排序
- 特征与预测结果的关系图
