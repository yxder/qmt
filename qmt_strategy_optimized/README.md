# 竞价打板策略框架

## 项目概述

本项目是一个基于Python开发的竞价打板策略框架，用于A股市场的集合竞价分析和投资决策生成。该框架通过多模块协同工作，实现从数据采集到最终投资决策的全流程自动化处理。

## 核心功能

1. **数据采集**：高效获取当日9:15-9:25集合竞价期间的全市场数据
2. **板块识别**：基于多维度指标评估体系筛选当日TOP热门板块
3. **个股筛选**：在热门板块内建立个股精选模型，设定严格的筛选条件
4. **模型预测**：应用机器学习模型对候选个股进行多维度评估
5. **风险评估**：对筛选出的个股进行全面风险评级
6. **决策生成**：整合各模块分析结果，形成系统化的投资决策建议

## 模块详细说明

### 1. 数据采集模块 (data/data_collector.py)

**功能**：精准获取当日9:15-9:25集合竞价期间的全市场数据

**采集内容**：
- 个股成交量、涨跌幅
- 资金流入流出情况
- 委托单数据
- 近3日成交量变化
- 价格波动率等衍生特征

**数据质量保障**：
- 完整性验证：确保关键字段无缺失
- 准确性验证：检查数据合理性和范围
- 实时性保障：30秒超时机制
- 异常数据过滤：自动剔除异常值

### 2. 板块识别模块 (strategy/sector_recognizer.py)

**功能**：基于采集的集合竞价数据，筛选出当日TOP热门板块

**评估指标**：
- 成交量增长率
- 涨跌幅偏离度
- 资金流入强度
- 板块联动性
- 板块涨停密度
- 板块相对强度
- 活跃股比例

**热度排序标准**：
- 综合评分 = 各指标标准化值 × 动态权重之和
- 动态权重：根据市场环境自动调整
- 热度阈值：基于板块综合评分的75分位数动态设定

### 3. 个股筛选模块 (strategy/stock_filter.py)

**功能**：在已识别的热门板块内，建立个股精选模型

**筛选条件**：
1. **近3日成交量持续放大**：每日增长率不低于30%
2. **早盘价格出现显著异动**：5%-9.5%
3. **流通盘规模适中**：50亿-200亿
4. **市场关注度指标达标**：竞价换手率0.5%-8%
5. **竞价强度足够**：成交量比≥1.5倍
6. **封单强度达标**：封单金额≥1000万，封单比例≥15%
7. **资金流入强劲**：资金净流入≥500万，大单占比≥60%

### 4. 模型预测模块 (strategy/model_predictor.py)

**功能**：应用预先训练的机器学习模型，对候选个股进行多维度评估

**预测指标**：
1. **未来30分钟内上涨概率**：0-1，置信区间±15%
2. **当日封板成功率**：0-1，置信区间±20%
3. **封板后次日溢价空间**：0-50%，置信区间±5%

**模型特性**：
- 支持多模型融合
- 提供SHAP特征重要性分析
- 动态计算预测置信度
- 包含完整的置信区间

### 5. 风险评估模块 (strategy/risk_evaluator.py)

**功能**：对筛选出的个股进行风险评级

**风险指标**：
- 市场整体情绪风险
- 个股历史波动率
- 流动性风险
- 政策风险
- 相关性风险
- 资金流风险
- 估值风险

**风险等级**：
- 低风险：风险评分 ≤ 0.3
- 中风险：0.3 < 风险评分 ≤ 0.6
- 高风险：风险评分 > 0.6

### 6. 决策建议生成 (strategy/decision_generator.py)

**功能**：整合各模块分析结果，形成系统化的投资决策建议

**决策内容**：
- 个股买入优先级
- 建议买入价格区间
- 精确的仓位配置比例
- 止盈止损点位
- 具体操作指引

**决策依据**：
- 模型预测分数 (40%)
- 个股综合评分 (35%)
- 风险评分 (25%)

## 关键参数说明

### 数据采集参数
- `max_workers`: 并行采集线程数
- `timeout`: 采集超时时间
- `quality_threshold`: 数据质量阈值

### 板块识别参数
- `top_n_sectors`: 筛选TOP板块数量
- `hotness_threshold`: 板块热度阈值

### 个股筛选参数
- `volume_growth_threshold`: 成交量增长率阈值
- `price_change_lower`: 价格异动下限
- `price_change_upper`: 价格异动上限
- `circulating_market_cap_range`: 流通盘范围

### 模型预测参数
- `confidence_threshold`: 预测置信度阈值
- `model_fusion_method`: 模型融合方法

### 风险评估参数
- `risk_weights`: 风险指标权重
- `risk_alert_thresholds`: 风险预警阈值

### 决策生成参数
- `max_single_position`: 单票最大仓位比例
- `max_total_position`: 总仓位最大比例
- `base_profit_target`: 基础止盈目标
- `base_stop_loss`: 基础止损比例
